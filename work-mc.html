WORKS ／ MC・司会者向けWebサイト

言葉を仕事にする人の、
信頼を伝えるサイト。

企業イベントから結婚式まで幅広く活動するMC・司会者のための、 依頼につながるプロフィールサイトを制作しました。

※ 掲載内容・画像は個人情報保護のため、サンプル用に変更しています。実際に制作したサイトの構成・デザインをもとにした匿名化サンプルです。

mio-sample.example
CATEGORY
MC / PERSON
PROJECT
MC・司会者向けプロフィールサイト
DESCRIPTION
司会・MCとして活動する個人の実績やプロフィールを整理し、仕事の依頼につながることを目的としたWebサイトを制作。
POINT
  • 実績を分かりやすく整理
  • プロフィールの信頼感を重視
  • スマートフォン最適化
  • 料金・FAQ・お問い合わせを設置
  • 仕事依頼につながる導線を設計
FUNCTION
  • レスポンシブ対応
  • お問い合わせフォーム
  • FAQ
  • 料金ページ
  • プロフィール
  • 実績紹介
  • スマートフォン対応
PERIOD
約3週間（サンプル）
STACK
HTML / CSS / JavaScript（フレームワーク不使用）

デザインの考え方

「企業案件」と「結婚式」という一見異なる依頼を、同じ一人のMCが引き受けられることが伝わるよう、 華やかになりすぎない上品な配色と、実績を数字で見せる構成を意識しました。

依頼する側が知りたい「実績」「人柄」「料金の目安」「よくある疑問」を過不足なく配置し、 読んだ流れの延長でお問い合わせに進めるよう導線を設計しています。
