# LUMINA WORKS コーポレートサイト

## ファイル構成
```
index.html          … TOPページ（1ページ内にSERVICE/WORKS/ABOUT/PRICE/FLOW/FAQ/CONTACTを構成）
privacy.html         … プライバシーポリシー
css/style.css        … デザイン（色・フォント・レイアウトはすべて変数管理）
js/config.js         … ★会社情報・料金・SNS・制作実績はここだけ編集すればOK
js/script.js         … サイトの挙動（設定の反映、アコーディオン、フォーム等）
assets/              … 画像・favicon置き場（現在はプレースホルダー）
```

## そのほか公開前に必要な作業

1. `assets/` に実際の写真（代表者プロフィール写真、制作実績サムネイル、OGP画像、favicon）を追加し、`config.js` および `index.html` の `og:image` を差し替える。
2. `index.html` / `privacy.html` 内の `https://example.com/` を実際のドメインに置き換える（`canonical`、構造化データ、OGP）。
3. お問い合わせフォーム（`js/script.js` の送信処理部分）を、実際の送信先（フォーム送信サービスまたは自社サーバーのAPI）に接続する。現状はデモとして完了画面を表示するのみで、実際の送信は行われません。
4. `privacy.html` の内容は一般的な構成の仮文面です。公開前に弁護士等の専門家による確認を推奨します。
5. 法人登記が完了した際は、会社名・所在地・代表者名を正式なものに更新する。
